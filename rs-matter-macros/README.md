# rs-matter-macros

### Proc-macros for the Rust implementation of Matter.

* Proc-macros for deriving the `FromTLV` and `ToTLV` traits.

NOTE: The macros are re-exported by the `rs-matter` crate which should be used instead of adding a direct dependency on the `rs-matter-macros` crate. Also, all `rs-matter-*` crates share one version, so the minor version of this crate might change without any breaking changes to it, or without any changes at all.

See `rs-matter` for more information.
