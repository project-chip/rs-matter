# rs-matter-codegen

### Build-time code generation for the Rust implementation of Matter.

NOTE: This crate is an internal dependency of `rs-matter` and is not expected to be used directly by the user. Also, all `rs-matter-*` crates share one version, so the minor version of this crate might change without any breaking changes to it, or without any changes at all.

See `rs-matter` for more information.
